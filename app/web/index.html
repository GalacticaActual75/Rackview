          Rackview login, storage and Git sync

          In Arcane, open this project’s Configuration → .env. DASHBOARD_USER and DASHBOARD_PASSWORD set the dashboard login. RACKVIEW_DATA_SOURCE selects the persistent mount. Arcane uses its Git credential to sync the repository. Arcane setup and deploy keys

          Find the iDRAC IP and login

          Use the management address you open for Dell iDRAC, or the address after -H in your working ipmitool command. The username follows -U. Enter the password for that iDRAC account.

          Optional fan duty readback over SSH

          In iDRAC8, open Overview → iDRAC Settings → Network → Services and enable SSH on port 22. Save the iDRAC address in Rackview, then find its host key.

          Overview checks the reported duty when it opens. Select Check fan duty to take another reading.

          TrueNAS read-only API

          Use a dedicated Read-Only Administrator account and its user API key.

          Find the TrueNAS HTTPS port

          In the TrueNAS shell, run midclt call system.general.config | jq .ui_httpsport. Enter the server’s HTTPS address with that port. You can keep using HTTP for your TrueNAS web interface.

          Choose a read-only account

          In Credentials → Users, add a dedicated user. Enable TrueNAS Access → Readonly Admin and leave Shell Access and SSH Access off. Enter the username that owns the API key.

          Create the TrueNAS API key

          In TrueNAS, open the top-right user menu and choose My API Keys → Add API Key. Select the read-only user, save, and copy the key while it is displayed. TrueNAS key guide

          Find the TrueNAS certificate fingerprint

          ⓘ VNC setup

          Enable VNC on iDRAC

          • iDRAC7 and iDRAC8Overview → iDRAC Settings → Network → Services
          • iDRAC9 and iDRAC10Configuration → Virtual Console

          In VNC Server, enable the service, set the VNC password and port, choose SSL encryption, and click Apply. Enter the same port, password, and encryption setting in Rackview.

          VNC requires an iDRAC license that includes the feature. iDRAC8 requires Enterprise.

          Reuse a previous console connection

          After a successful VNC login, Rackview saves the port, TLS setting, and fingerprint for this iDRAC. Select a profile to restore those settings. Forget saved connection removes the profile and its saved password.

          Find the VNC password

          Use the password configured under VNC Server in iDRAC. The VNC setup guide above shows the path for your iDRAC version. Select Remember VNC password to reuse it after a successful connection.

          Find the VNC certificate fingerprint

          With TLS enabled, run this from a trusted management shell with OpenSSL. It checks the iDRAC VNC service on the selected port.Verify the certificate and copy the fingerprint after =.

          Use the VNC-specific password. A self-signed TLS certificate needs a verified fingerprint.
