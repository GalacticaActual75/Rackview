ⓘ VNC setup

Enable VNC on iDRAC

  • iDRAC7 and iDRAC8Overview → iDRAC Settings → Network → Services
  • iDRAC9 and iDRAC10Configuration → Virtual Console

In VNC Server, enable the service, set the VNC password and port, choose SSL encryption, and click Apply. Enter the same port, password, and encryption setting in Rackview.

VNC requires an iDRAC license that includes the feature. iDRAC8 requires Enterprise.

Use the VNC-specific password. A self-signed TLS certificate needs a verified fingerprint.
